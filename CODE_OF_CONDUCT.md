# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolhedor e construtivo. Assédio, discriminação ou ataques pessoais
não são tolerados em issues, pull requests ou qualquer outro espaço do projeto.

Comportamentos inaceitáveis podem ser reportados aos mantenedores pelo recurso de
reporte privado do GitHub ou por mensagem direta ao mantenedor do repositório.
